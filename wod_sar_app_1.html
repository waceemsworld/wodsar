  1. Open Google Sheets → create a new sheet named WOD_SAR

  3. Go to Extensions → Apps Script, paste the provided script, and deploy as a Web App (Anyone access)
  4. Paste your deployed Web App URL below:
  5. ⚠️ If you already deployed before: go to Deploy → Manage deployments → edit your deployment → set version to New version → Update. The URL stays the same.
